## 面数据表的通用约定

几乎所有专利都用同一套约定，先确认它成立再录入：

- **一行 = 一个光学面**，从物侧数起。
- **R（曲率半径 / RDY / 曲率半径 r）**：对物体凸为正、凹为负。平面写 `∞` / `Infinity` / `inf` / `无穷大`。
- **D（间隔 / THI / 面間隔 / 厚度）**：**本面到下一面**的距离。最后一行的 D 就是后焦 BF。
- **nd / νd**：该面**之后**那段介质的折射率与阿贝数。空白 = 空气。
- **胶合面共用一行**：所以一组胶合双胶合镜只占 3 行，不是 4 行。日文写作
  「L17 の像側面と L18 の物側面」，中文写作「透镜L21的像侧面和透镜L22的物侧面」。
- **光阑**单占一行，R 为无穷大，标记为 `STO` / `絞り` / `光圈面` / `(絞り)`。
  在 spec 里给这一行加 `"stop": true`。
- **可变间隔**在表里写成符号（`(可変)` / `D1` / `THI(26)`），数值另表给出。

### 变量间隔怎么落到 spec

专利用两种写法，都要还原成"哪一面之后的间隔在变"：

1. **符号写在 D 列**（`D1`、`(可変)`）→ 该行的 D 就是变量。
2. **只在正文写 `THI(26)`** → 括号里的数字是**行号**（从第 1 面数起、光阑也算一行）。
   核对方法：去表里数到第 26 行，它的 D 值应当等于对焦表里"∞"那一列的值。
   对不上就说明行号或透镜编号有误 —— **以数值对得上者为准**。

## 日本 JP-A（特开）

- 正文是文字层，`pdftotext -layout` 能抽。若抽出乱码或空白，装 `poppler-data` 补 CJK CMap。
- 表格标记 `【表１】`、`【表２】`…，或「面データ」「レンズデータ」小节。
  较老的写法（如佳能、尼康）是纯文本表，直接读；较新的常把表做成图片。
- 用页眉 `(7) JP 2025-108279 A` 定位页码，页眉里的数字就是 PDF 页号。
- 变焦镜头会有「各種データ」（焦距/FNo/画角/像高/全长/BF）和
  「レンズユニット（群）データ」，都值得放进 `general`。
- 「数値実施例N」与「実施例N」编号常常不一致 —— 例如 JP2013140404A 里
  参考例1〜4 = 数値例1〜4，而**実施例1 = 数値例5**。录入前先在正文确认对应关系。

## 中国 CN-A（发明专利申请）

- 说明书正文是文字层，但**表格几乎总是图片**，必须渲染后视觉识别。
- 表头常见「面序号 / 面型 / 球面半径 / 厚度 / 折射率 / 阿贝数」或
  「透镜表面 / RDY / THI / 折射率 Nd / 阿贝数 Vd」。
- 后者用"透镜Lxx的物侧面/像侧面"而不是面号，此时**面号要自己按行数编**，
  正文引用的 `THI(n)` 就是这个行号。
- 用 `说 明 书 N/M 页` 页眉配合正文里的「如下表」定位页码。
- 折射率常只给 2 位小数、阿贝数 3~4 位有效数字。这种低精度会显著影响玻璃匹配，
  `glasslib.py` 会自动放宽容差，但要在回话里如实说明。
- 多个实施例的说明文字经常是复制粘贴的（第三实施例里写着"本实施例二"），
  编号别照抄，**以表格数值为准**。

## 美国 US / WO

- 表格通常是文字层，列名 `Surface`、`R`、`D`、`Nd`、`Vd`，或 CODE V 原生的
  `RDY` / `THI` / `GLA`。
- `GLA` 列可能直接给玻璃牌号（`S-BSL7_OHARA`），这种情况下玻璃匹配只是核对，
  仍然照跑，Δ 应当全为 0。
- 单位可能是英寸，注意 `Dimensions:` 声明。

## 已知陷阱清单

按踩到的频率排序。这些都是真实案例，看到类似征兆就要停下来核对。

**1. 厚度列整体错位。** 症状：某个带玻璃的面，D 写成了可变量（玻璃厚度不可能变化）；
或某片透镜厚度小到 0.13 mm；或相邻两行 D 值完全重复。
核对办法：拿同一专利里结构相同的另一个实施例对照，正常的那个能反推出错位方向。

**2. 折射率/阿贝数写错行。** 症状：滤光片那一行没有玻璃，而它下面"到像面"的行反而有玻璃。
一样用同专利的其他实施例对照。

**3. 正文与表格数值不符。** 例如正文写「νd＝81.86」而表里是 81.61。
**以表格为准**，正文当误记处理，并在 `note` 里注明。

**4. 非球面系数的面编号与面号差一位。** 症状：表里标 `S7`、`S8`，但"面型"列显示
第 6、7 面才是非球面。以"面型"列和透镜构成为准。

**5. 正文描述的透镜编号偏移。** 例如正文说"L28像侧面与L29物侧面之间的空气间隔"，
但按行号 `THI(28)` 落在 L27 的像侧面。以数值对得上者为准。

**6. 正文的正负透镜片数与实际不符。** 专利里"由六片正透镜和一片负透镜构成"这类描述
经常不准。需要时自己按 `(n-1)(1/R1 - 1/R2)` 估一下光焦度符号，别照抄正文。

**7. 结构性遗漏。** 光阑那一行的间隔在印刷中丢失、最后一行 D 偏离其他实施例一大截，
这类只能靠交叉对照发现。发现了如实标注，不要凭空补数。

处理原则统一：**表里保留印刷原值**，把疑点写进该行 `note`（以 `★` 开头，会自动标红），
必要时再加一列/一段说明建议值。不要静默修改专利数据。
